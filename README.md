# AI Career Operating System 🚀

AI-powered full-stack career platform that helps users discover jobs, track applications, and get intelligent career recommendations.

## Features

- AI-based job matching
- Job aggregation from multiple sources
- Career insights dashboard
- Application tracking
- REST API backend
- Modern React frontend

## Tech Stack

Backend:
- Java
- Quarkus
- REST APIs

Frontend:
- React
- Vite

Database:
- MySQL
- Flyway

AI:
- Claude AI Integration

## Architecture

Frontend → Backend API → Database → AI Services
